# 処理時間の目安（ベンチマーク）

> 実測は短いクリップ（数秒〜十数秒）での値、1時間あたりは推定の目安です。
> 環境: Apple Silicon (MPS) / Python 3.12。音声品質・話者数・無音区間で変動します。
> 文字起こし（ASR）部分の性能はモデル・ハードウェア依存で、生成バックエンドの選択には影響されません。

## STT（文字起こし）実測 RTF

RTF = 処理時間 / 音声長（小さいほど速い）。faster-whisper / large-v3-turbo。

| 音声 | 言語 | RTF | 備考 |
|------|------|-----|------|
| 英語 ~13秒 | en | 0.303 | 最速 |
| 混合 ~16秒 | en検出 | 0.527 | 中間 |
| 日本語 ~4秒 | ja | 0.912 | 短い音声は初期化コストの比率が高くRTF悪化 |

短いクリップほどモデル初期化コストの影響で RTF が悪化します。実用的な長さ（1時間音声）では RTF 0.3〜0.5 程度に安定する傾向です。

## 1時間の音声を処理した場合の目安

### STT（文字起こし）

| プリセット | モデル | RTF（推定） | 1時間音声 |
|-----------|--------|------------|----------|
| B / D | large-v3-turbo | 0.3〜0.5 | 約 18〜30 分 |
| C | large-v3 | 0.5〜0.8 | 約 30〜48 分 |
| A | parakeet-tdt → whisper | 0.1〜0.3 | 約 6〜18 分（英語） |

### 生成（議事録・ノート等）

1時間分の文字起こし（プロンプト読み込みが支配的）。

| バックエンド | モデル例 | 1時間分 |
|------------|---------|--------|
| API (openai) | ChatGPT（推奨） | 数十秒〜（モデル依存） |
| API (gemini) | gemini-2.5-flash-lite | 約 10〜30 秒 |
| API (gemini) | gemini-2.5-flash | 約 30〜60 秒 |
| ローカル | mlx-vlm (Gemma 4 E4B) | 約 2〜3 分 |
| ローカル | mlx-lm (Qwen2.5-7B) | 約 2〜4 分 |
| `--output prompt` | （生成なし・API不使用） | 即時 |
